# Algorithmic Trading Strategies.

This project is a simple example of how to implement algorithmic trading strategies in Python.<br/>
The scope of the project includes trend detection, setting up entry and exit strategies, determining lot sizes, 
as well as backtesting using various technical indicators related to trend, momentum, volume, and volatility.<br/>
Since the aim of this project for exploration purpose only, the data used is Yahoo Finance not directly from Boker's API.
